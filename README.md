# Kemal Avsever

Yazilim ve yapay zeka alanlarinda kendini gelistiren bir yazilim muhendisligi ogrencisi.

## Hakkimda

- Radar sinyal isleme, derin ogrenme ve goruntu isleme uzerine projeler gelistiriyorum
